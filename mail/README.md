## Puntaje de perfil provisorio (sobre 100, calculado solo con el CV)

Se usa hasta que el puntaje salga de las entrevistas.

| Criterio | Puntos |
|---|---|
| Experiencia relacionada con el puesto | 40 |
| Calidad de los datos (CV completo, fechas, contacto verificable) | 20 |
| Movilidad propia o buen acceso al lugar | 15 |
| Cercanía entre la localidad del candidato y el puesto | 15 |
| Disponibilidad horaria compatible | 10 |

La edad, el género, el aspecto y el estado civil NO puntúan: son criterios discriminatorios.
Si un dato no figura en el CV, ese criterio suma 0 (nunca se supone).
